# OpenAI Cookbook 繁中教材

網站：https://ck10100713.github.io/agent-tutor/

把 [openai/openai-cookbook](https://github.com/openai/openai-cookbook) 整理成繁體中文教材。

- `docs/`：網站內容，程式碼直接放在頁面上
- `notebooks/`：需要 GPU 的篇，用 Colab 跑
- `build.py`：從 cookbook 原始檔產生上面兩者（cookbook 要 clone 在旁邊的 `../openai-cookbook`）
- `TRANSLATE_RULES.md`：翻譯規則
