## 這篇在做什麼

這篇示範 prompt chaining：把 Claude 前一次的回答放進下一個 prompt，請它檢查或改進。用字詞清單和短篇故事兩個例子，看多一輪呼叫怎麼讓答案更準、更好。

## 學完你會

- 用兩次呼叫的 chain，讓 Claude 修正自己上一輪答錯的內容。
- 在 prompt 裡給 Claude 一條「沒問題就維持原樣」的退路，降低它把正確答案改壞的機率。
- 用 substitution 把第一次呼叫的結果（故事、名單）塞進第二個更長的 prompt。

client = anthropic.Anthropic(api_key=API_KEY)

# Has been rewritten to take in a messages list of arbitrary length
def get_completion(messages, system_prompt=""):
    message = client.messages.create(
        model=MODEL_NAME,
        max_tokens=2000,
        temperature=0.0,
        system=system_prompt,
        messages=messages
    )

## 課程

俗話說「寫作就是不斷重寫」。**請 Claude 修正答案，常常能讓它的回答更準確**！

要請 Claude「再想一次」有很多方法。你會自然拿來請人複查工作的說法，通常對 Claude 也有效。（想看更多什麼時候、怎麼用 prompt chaining 的例子，可以看我們的 [prompt chaining 文件](https://docs.anthropic.com/claude/docs/chain-prompts)。）

### 範例

這個例子裡，我們請 Claude 想出十個單字……但其中有一個或多個不是真正的單字。

```python
# Initial prompt
first_user = "Name ten words that all end with the exact letters 'ab'."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    }
]

# Store and print Claude's response
first_response = get_completion(messages)
print(first_response)
```

**請 Claude 讓答案更準確**就修好了錯誤！

下面我們把上面 Claude 的錯誤回答拿下來，再加一個 turn 到對話裡，請 Claude 修正它之前的答案。

```python
second_user = "Please find replacements for all 'words' that are not real words."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(get_completion(messages))
```

但 Claude 修改答案，是不是只因為我們叫它改？如果一開始就是正確答案呢？它會失去信心嗎？這裡我們把一份正確的回答放在 `first_response` 的位置，再請它複查一次。

```python
first_user = "Name ten words that all end with the exact letters 'ab'."

first_response = """Here are 10 words that end with the letters 'ab':

1. Cab
2. Dab
3. Grab
4. Gab
5. Jab
6. Lab
7. Nab
8. Slab
9. Tab
10. Blab"""

second_user = "Please find replacements for all 'words' that are not real words."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(get_completion(messages))
```

你可能會發現，上面那個區塊多生成幾次回應，Claude 大部分時候會維持原樣，但偶爾還是會改動單字，即使它們全都已經是對的。要怎麼減少這種情況？照第 8 章的做法，給 Claude 一條退路！我們再試一次。

8. Slab

10. Blab"""

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": first_response

多生成幾次上面程式的回應，你會看到 Claude 現在更能堅持自己的答案了。

你也可以用 prompt chaining **請 Claude 把它的回應變得更好**。下面我們請 Claude 先寫一個故事，再改進它寫的故事。口味因人而異，但很多人會同意 Claude 的第二版比較好。

首先，讓 Claude 生成第一版故事。

```python
# Initial prompt
first_user = "Write a three-sentence short story about a girl who likes to run."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    }
]

# Store and print Claude's response
first_response = get_completion(messages)
print(first_response)
```

現在讓 Claude 改進它的初稿。

```python
second_user = "Make the story better."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(get_completion(messages))
```

這種 substitution 的形式非常強大。我們一直用 substitution placeholder 來傳入清單、單字、Claude 先前的回應等等。你也可以**用 substitution 做我們所謂的「function calling」：請 Claude 執行某個函式，再拿函式的結果請 Claude 接著做更多事**。它跟其他 substitution 的運作方式一樣。下一個附錄會有更多說明。

下面還有一個例子，把一次 Claude 呼叫的結果，塞進另一個更長的呼叫。先從第一個 prompt 開始（這次包含預填 Claude 的回應）。

```python
first_user = """Find all names from the below text:

"Hey, Jesse. It's me, Erin. I'm calling about the party that Joey is throwing tomorrow. Keisha said she would come and I think Mel will be there too."""

prefill = "<names>"

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": prefill
    
    }
]

# Store and print Claude's response
first_response = get_completion(messages)
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(first_response)
```

把這份名單傳進另一個 prompt。

```python
second_user = "Alphabetize the list."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": prefill + "\n" + first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response

```

## 重點整理

- Claude 常常能在被要求「再檢查一次」之後改善答案，做法就是把上一輪回答放進下一個 prompt。
- 對一個已經正確的答案要求複查，Claude 偶爾會改壞它，給它「沒錯就不用改」的退路可以降低這種情況。
- prompt chaining 也能用來提升品質，例如先寫初稿，再請 Claude 改進。
- 用 substitution 把前一次呼叫的輸出塞進下一個 prompt，就是 function calling 的基礎做法。

## 練習

1. 把單字例子的任務換成另一種（例如「列出十個真實存在的國家」），故意在 `first_response` 放一個錯誤，看第二輪能不能抓到。
2. 在複查 prompt 裡拿掉「給退路」的那句話，對正確的答案多生成十次，數一數有幾次被改動，再加回去比較。
3. 把故事的 chain 擴成三輪：初稿、改進、再依指定風格（例如更幽默）改寫，觀察每一輪的差異。
