## 這篇在做什麼

說明 Claude 可以幫你搜尋 Wikipedia 或你自己的文件，找到內容後還能摘要、整合、寫新內容。這篇主要是指向 RAG 相關資源的附錄，沒有程式碼要跑。

## 學完你會

- 知道 Claude 可以搭配檢索去查 Wikipedia、純文字文件或 vector datastore
- 知道去哪裡找 RAG cookbook 範例
- 知道去哪裡看進階 RAG 架構的簡報

你知道可以用 Claude **幫你搜尋 Wikipedia** 嗎？Claude 能找到並取回文章，接著你也可以用 Claude 把這些文章摘要、整合，根據找到的內容寫新的內容，還有更多用法。而且不只 Wikipedia！你也可以搜尋自己的文件，不管是存成純文字，還是嵌入在 vector datastore 裡。

請看我們的 [RAG cookbook 範例](https://github.com/anthropics/anthropic-cookbook/blob/main/third_party/Wikipedia/wikipedia-search-cookbook.ipynb)，學習怎麼用從 vector database、Wikipedia、網路等地方取回的資料，補充 Claude 的知識，提高 Claude 回應的準確度和相關性。在那裡你也能學到怎麼使用特定的 [embeddings](https://docs.anthropic.com/claude/docs/embeddings) 和 vector database 工具。

如果你想學用 Claude 的進階 RAG 架構，可以看我們的 [Claude 3 RAG 架構技術簡報](https://docs.google.com/presentation/d/1zxkSI7lLUBrZycA-_znwqu8DDyVhHLkQGScvzaZrUns/edit#slide=id.g2c736259dac_63_782)。

## 重點整理

- 檢索能補充 Claude 的知識，提升回應的準確度和相關性。
- 檢索來源可以是 Wikipedia、網路、你自己的純文字文件或 vector database。
- 取回資料後，Claude 可以做摘要、整合和生成新內容。
- 進階的 RAG 架構有專門的資源可以延伸學習。

## 練習

1. 讀一下 Wikipedia search cookbook，挑一個你有興趣的主題照著跑一遍。
2. 把你自己的幾份純文字文件當作檢索來源，試著用同樣的做法問問題。
