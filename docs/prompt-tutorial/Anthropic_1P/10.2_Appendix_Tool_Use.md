## 這篇在做什麼

Tool use（也叫 function calling）其實就是「代換」加上「prompt chaining」。這篇用一個計算機 tool，從頭到尾手動走完一次：Claude 輸出要呼叫的 tool 跟參數、你執行 function、再把結果餵回去。

## 學完你會

- 寫出 tool use 的 system prompt，包含通用說明跟特定 tool 的定義。
- 用 `stop_sequences` 偵測 Claude 的 function call，解析參數並執行，再把結果格式化後回傳。
- 為一個簡單的字典「資料庫」寫 `add_user`、`add_product`、`get_user`、`get_product` 的 tool 定義。

## Setup

執行下面的 setup cell，載入 API key 並建立 `get_completion` 這個 helper function。

```python

# Import python's built-in regular expression library
import re
import anthropic

# Retrieve the API_KEY variable from the IPython store
%store -r API_KEY

client = anthropic.Anthropic(api_key=API_KEY)

# Rewrittten to call Claude 3 Sonnet, which is generally better at tool use, and include stop_sequences
def get_completion(messages, system_prompt="", prefill="",stop_sequences=None):
    message = client.messages.create(
        model="claude-3-sonnet-20240229",
        max_tokens=2000,
        temperature=0.0,
        system=system_prompt,
        messages=messages,
        stop_sequences=stop_sequences
    )
    return message.content[0].text
```

## Lesson

乍看之下 tool use（又稱 function calling）概念好像很複雜，但其實很簡單！你已經具備實作 tool use 需要的所有技能，它其實就是代換跟 prompt chaining 的組合。

之前的代換練習是把文字代入 prompt。Tool use 則是把 tool 或 function 的結果代入 prompt。Claude 沒辦法真的呼叫或存取 tool 跟 function，所以我們的做法是讓 Claude：
1. 輸出它想呼叫的 tool 名稱和參數
2. 在 tool 被呼叫期間，停止繼續生成回應
3. 然後我們附上 tool 結果，重新對它下 prompt

Function calling 很有用，因為它擴充了 Claude 的能力，讓 Claude 能處理複雜得多的多步驟任務。
可以給 Claude 的 function 例子：
- 計算機
- 字數統計
- SQL 資料庫查詢與資料擷取
- 天氣 API

要讓 Claude 使用 tool，要結合這兩個元素：

1. System prompt：向 Claude 說明 tool use 的概念，並詳細列出它能使用的 tool
2. 控制邏輯：用來協調並執行 Claude 的 tool use 請求

### Tool use 路線圖

*這一課教的是我們目前的 tool use 格式。不過我們近期會更新並改進 tool use 功能，包括：*
* *更精簡的 function 定義與呼叫格式*
* *更穩健的錯誤處理與邊界情況涵蓋*
* *與 API 其他部分更緊密的整合*
* *更好的可靠度與效能，特別是更複雜的 tool use 任務*

### 範例

要讓 Claude 能用 tool，我們先從 system prompt 開始。在這個特殊的 tool use system prompt 裡，我們告訴 Claude：
* tool use 的基本概念和包含的內容
* Claude 該怎麼呼叫並使用拿到的 tool
* 在這個特定情境下它能用的 tool 詳細清單

下面是 system prompt 的第一部分，向 Claude 說明什麼是 tool use。這一部分在所有讓 Claude 用 tool 的 prompt 中都通用。我們給 Claude 的 tool 呼叫結構（`<function_calls> [...] </function_calls>`）是 Claude 特別訓練過的結構，所以建議你照著用。

```python
system_prompt_tools_general_explanation = """You have access to a set of functions you can use to answer the user's question. This includes access to a
sandboxed computing environment. You do NOT currently have the ability to inspect files or interact with external
resources, except by invoking the below functions.

You can invoke one or more functions by writing a "<function_calls>" block like the following as part of your
reply to the user:
<function_calls>
<invoke name="$FUNCTION_NAME">
<antml:parameter name="$PARAMETER_NAME">$PARAMETER_VALUE</parameter>
...
</invoke>
<nvoke name="$FUNCTION_NAME2">
...
</invoke>
</function_calls>

String and scalar parameters should be specified as is, while lists and objects should use JSON format. Note that
spaces for string values are not stripped. The output is not expected to be valid XML and is parsed with regular
expressions.

The output and/or any errors will appear in a subsequent "<function_results>" block, and remain there as part of
your reply to the user.
You may then continue composing the rest of your reply to the user, respond to any errors, or make further function
calls as appropriate.
If a "<function_results>" does NOT appear after your function calls, then they are likely malformatted and not
recognized as a call."""
```

第二部分的 system prompt 則定義這個特定情境下 Claude 能用的確切 tool。這個範例中，我們給 Claude 一個計算機 tool，它有三個參數：兩個運算元跟一個運算子。

然後把兩部分的 system prompt 合併起來。

```python
system_prompt_tools_specific_tools = """Here are the functions available in JSONSchema format:
<tools>
<tool_description>
<tool_name>calculator</tool_name>
<description>
Calculator function for doing basic arithmetic.
Supports addition, subtraction, multiplication
</description>
<parameters>
<parameter>
<name>first_operand</name>
<type>int</type>
<description>First operand (before the operator)</description>
</parameter>
<parameter>
<name>second_operand</name>
<type>int</type>
<description>Second operand (after the operator)</description>
</parameter>
<parameter>
<name>operator</name>
<type>str</type>
<description>The operation to perform. Must be either +, -, *, or /</description>
</parameter>
</parameters>
</tool_description>
</tools>
"""

system_prompt = system_prompt_tools_general_explanation + system_prompt_tools_specific_tools
```

現在可以問 Claude 一個需要用 `calculator` tool 的問題。我們在 `stop_sequences` 放 `<function_calls\>`，用來偵測 Claude 是否呼叫 function、什麼時候呼叫。

```python
multiplication_message = {
    "role": "user",
    "content": "Multiply 1,984,135 by 9,343,116"
}

stop_sequences = ["</function_calls>"]

# Get Claude's response
function_calling_response = get_completion([multiplication_message], system_prompt=system_prompt, stop_sequences=stop_sequences)
print(function_calling_response)
```

接著，我們可以從 Claude 的 function call 取出參數，代替 Claude 實際執行 function。

先定義 function 的程式碼。

```python
def do_pairwise_arithmetic(num1, num2, operation):
    if operation == '+':
        return num1 + num2
    elif operation == "-":
        return num1 - num2
    elif operation == "*":
        return num1 * num2
    elif operation == "/":
        return num1 / num2
    else:
        return "Error: Operation not supported."
```

然後從 Claude 的 function call 回應取出參數。如果參數都齊全，就執行計算機 tool。

```python
def find_parameter(message, parameter_name):
    parameter_start_string = f"name=\"{parameter_name}\">"
    start = message.index(parameter_start_string)
    if start == -1:
        return None
    if start > 0:
        start = start + len(parameter_start_string)
        end = start
        while message[end] != "<":
            end += 1
    return message[start:end]

first_operand = find_parameter(function_calling_response, "first_operand")
second_operand = find_parameter(function_calling_response, "second_operand")
operator = find_parameter(function_calling_response, "operator")

if first_operand and second_operand and operator:
    result = do_pairwise_arithmetic(int(first_operand), int(second_operand), operator)
    print("---------------- RESULT ----------------")
    print(f"{result:,}")
```

有了結果之後，要把結果格式化好，這樣傳回給 Claude 時，Claude 才知道這個結果是對應哪個 tool 的。Claude 訓練時學過一個固定的格式來辨識：
```
<function_results>
<result>
<tool_name>{TOOL_NAME}</tool_name>
<stdout>
{TOOL_RESULT}
</stdout>
</result>
</function_results>
```

執行下面的 cell，把上面的 tool 結果格式化成這個結構。

```python
def construct_successful_function_run_injection_prompt(invoke_results):
    constructed_prompt = (
        "<function_results>\n"
        + '\n'.join(
            f"<result>\n<tool_name>{res['tool_name']}</tool_name>\n<stdout>\n{res['tool_result']}\n</stdout>\n</result>"
            for res in invoke_results
        ) + "\n</function_results>"
    )

    return constructed_prompt

formatted_results = [{
    'tool_name': 'do_pairwise_arithmetic',
    'tool_result': result
}]
function_results = construct_successful_function_run_injection_prompt(formatted_results)
print(function_results)
```

現在只要把這個結果附加到先前同一串訊息後面，送回給 Claude 就完成了！

```python
full_first_response = function_calling_response + "</function_calls>"

# Construct the full conversation
messages = [multiplication_message,
{
    "role": "assistant",
    "content": full_first_response
},
{
    "role": "user",
    "content": function_results
}]
   
# Print Claude's response
final_response = get_completion(messages, system_prompt=system_prompt, stop_sequences=stop_sequences)
print("------------- FINAL RESULT -------------")
print(final_response)
```

恭喜你完整跑完一次 tool use 的流程！

那如果給 Claude 一個根本不需要用到那個 tool 的問題呢？

### Exercise 10.2.1 - SQL
這個練習要你寫一個 tool use prompt，用來查詢並寫入全世界最小的「資料庫」。下面是初始化好的資料庫，其實就是一個 dictionary。

```python
db = {
    "users": [
        {"id": 1, "name": "Alice", "email": "alice@example.com"},
        {"id": 2, "name": "Bob", "email": "bob@example.com"},
        {"id": 3, "name": "Charlie", "email": "charlie@example.com"}
    ],
    "products": [
        {"id": 1, "name": "Widget", "price": 9.99},
        {"id": 2, "name": "Gadget", "price": 14.99},
        {"id": 3, "name": "Doohickey", "price": 19.99}
    ]
}
```

這是對資料庫讀寫的 function 程式碼。

```python
def get_user(user_id):
    for user in db["users"]:
        if user["id"] == user_id:
            return user
    return None

def get_product(product_id):
    for product in db["products"]:
        if product["id"] == product_id:
            return product
    return None

def add_user(name, email):
    user_id = len(db["users"]) + 1
    user = {"id": user_id, "name": name, "email": email}
    db["users"].append(user)
    return user

def add_product(name, price):
    product_id = len(db["products"]) + 1
    product = {"id": product_id, "name": name, "price": price}
    db["products"].append(product)
    return product
```

要解這題，先像上面的 `system_prompt_tools_specific_tools` 一樣定義一個 system prompt。要包含每個 tool 的名稱跟描述，以及每個 function 每個參數的名稱、型別跟描述。下面提供了一些起手的 scaffold。

```python
system_prompt_tools_specific_tools_sql = """
"""

system_prompt = system_prompt_tools_general_explanation + system_prompt_tools_specific_tools_sql
```

## 重點整理

- Tool use 的本質是代換加 prompt chaining：Claude 只輸出要呼叫什麼，真正執行的是你的程式。
- 流程是三步：Claude 輸出 tool 名稱與參數、停止生成、你附上結果再 prompt 一次。
- System prompt 分兩部分：通用的 tool use 說明，加上這個情境專屬的 tool 清單。
- 結果要用 Claude 訓練時學過的固定格式包起來，它才知道結果對應哪個 tool。
- 不需要 tool 的問題，Claude 會自己判斷不呼叫。
